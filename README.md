# 5-code-signal-practice-tests
This repository contains 5 CodeSignal-style coding assessments created as preparation for a technical selection process.

The assessments follow a progressive difficulty, gradually approaching the real CodeSignal coding test level. 

# Description: 

- practice-test-01 -> Language: PT-BR🇧🇷. Introduces basic Python logic, lists, dictionaries, functions, and state management.
- practice-test-02 -> Language: EN-US🇺🇸. Builds on the fundamentals with multiple entities, inventory management, validation, and data manipulation.
- practice-test-03 -> Language: EN-US🇺🇸. Introduces more complex logic with task management, filtering, sorting, priorities, and workload analysis.
- practice-test-04 -> Language: EN-US🇺🇸. Advances into object-oriented programming and interactions between multiple entities in a delivery management system.
- practice-test-05 -> Language: EN-US🇺🇸. Combines the concepts from previous tests in a more complex event booking system. With the help of AI, a 'tests' folder and 'run_tests' notebook were also developed to automate requirement validation and identify errors, simulating the testing experience of platforms such as CodeSignal.

# Topics Covered:

- Logical reasoning
- Functions and methods
- Lists and dictionaries
- Object-oriented programming
- Classes and inheritance
- Sorting and data manipulation
- Type hints
- Lambda functions
- Problem solving and edge cases
- Automated testing

# Observations and Personal Experience:

1. Aside from the CodeSignal programming structure, I also tried to simulate the CodeSignal conditions in every one of the practices, i.e., No AI or outside help during the tests. 90 minutes time limit. No stoping after the test is started.    

2. My performance gets better with each assesment, but I did not manage to Ace any of them. The CodeSignal plataform itself suggests that, in most cases, the 90 minutes are not enough to get through the 4 levels of the test. So, I just did my best with every attempt.

3. Overall, it was a fun practice that made me learn a lot of new Python structures and tools, train my logical reasoning and helped me deal with programming, debugging and optimize code under a severe deadline.
